# 🏐 Vôlei — Treinos, glossário e saúde

Voltar: [[volei]] · Relacionados: [[volei-fundamentos]] · [[volei-regras]] · [[volei-posicoes-rotacao]]

## Glossário
| Termo | Significado |
|---|---|
| Ace | saque que dá ponto direto |
| Cortada/Smash | ataque forte de cima para baixo |
| Largada | toque suave no ataque, atrás do bloqueio |
| Manchete | passe com os antebraços |
| Toque | passe com as pontas dos dedos |
| Tempo | ataque rápido ritmado com o levantador |
| Rally | sequência de toques até o ponto |
| Side-out | ponto de quem recebeu o saque |
| Break | ponto de quem sacou |
| Pipe | ataque de fundo |
| Líbero | especialista em defesa, uniforme diferente |
| Tie-break | 5º set de desempate (até 15) |

## Treino técnico (exemplo 60–90 min)
1. **Aquecimento** (10 min): mobilidade de ombros/quadril + toques em dupla.
2. **Passe** (15 min): manchete em dupla → em movimento.
3. **Levantamento** (10 min): parede/dupla, só dedos.
4. **Saque** (15 min): alvos em zonas 1/5/meio.
5. **Ataque + bloqueio** (20 min): aproximação, salto, golpe.
6. **Jogo reduzido** (20 min): 3×3 ou 4×4 para repetir situações.

## Preparação física
- **Explosão:** saltos (agachamento com salto, caixa), pliometria.
- **Força:** pernas, core, ombros (manguito), costas.
- **Mobilidade:** ombro, tornozelo, quadril.
- **Resistência:** intervalado curto (jogo tem rallies de 5–15 s).

## Lesões comuns e prevenção
| Região | Causa | Prevenção |
|---|---|---|
| Tornozelo | aterrissagem torta/invasão sob a rede | reforço + propriocepção, calçado adequado |
| Joelho ("joelho de saltador") | saltos repetidos | fortalecer quadríceps/posterior, dosar volume |
| Ombro | ataque/saque repetidos | fortalecimento do manguito, alongar |
| Dedos | bloqueio/toque | tapear e usar técnica correta |
