# Call of Cthulhu 7e / BRP (pesquisa)

Parte de [[pesquisa-sistemas-rpg]].
- **[web]** d100 **igual ou abaixo** da perícia (0–100%). **Crítico** = 1; **extremo** ≤ 1/5; **difícil** ≤ 1/2; **normal** ≤ perícia. Desastre: 100 (perícia >50) ou ≥96 (perícia <50).
- **[web]** **Forçar rolagem** (push): uma vez após falhar, justificada na ficção; se falhar de novo, o Guardião impõe algo pior. Combate e Sanidade não se forçam.
- **[web]** **Sanidade**: d100 ≤ SAN atual; perda por falha (formato **X/Y**: perda no sucesso/falha); perda grande num período = insanidade temporária ou indefinida; SAN praticamente só desce; máx. = 99 − Mythos (fonte única, baixa qualidade).
- **[web]** **Ferimento grave** = perder ≥ metade dos PV máx. de uma vez; 0 PV sem grave = inconsciente; 0 PV com grave = **morrendo** (Primeiros Socorros estabiliza, depois Medicina). Morrendo pode **gastar a Sorte inteira (mín. 30)** para escapar: volta 1d6+1 PV.
- Ideias p/ Nexus: Sorte como recurso que paga **resgate** (já existe "Ponto de sorte"); grau de sucesso por fração da perícia.
