# Comparativo: resolução, ações, morte, movimento

Parte de [[pesquisa-sistemas-rpg]]. O que o Nexus já faz: [[nexus-rpg-morte-movimento-assistentes]].

| Sistema | Resolução | Ações/turno | A 0 PV | Salvar |
|---|---|---|---|---|
| D&D 5e | d20 + mod + prof vs CD | 1 ação + bônus + reação + mover | 3 sucessos / 3 falhas | Medicina CD 10, cura |
| Ordem Paranormal | d20 (pool de atributo) + perícia [memória] | padrão/movimento [memória] | cai/morrendo (a confirmar) | socorro |
| Tormenta20 | d20 + atrib + ½ nível + treino [memória] | padrão/mov./completa/livre/reação [memória] | condições (Sangrando…) | cura |
| Fate | 4dF + perícia vs escada | uma ação por turno | estresse → consequência → fora/conceder | conceder |
| Pathfinder 2e | d20 + nível + rank, 4 graus | 3 + reação | dying/wounded [memória] | pontos de herói |
| Call of Cthulhu | d100 ≤ perícia, 4 graus | 1 ação | ferimento grave → morrendo | Sorte, 1ºs socorros |

## Famosos não verificados (só [memória]; fazer busca dedicada)
- **Vampiro V5:** pool de d10 + dados de Fome. **PbtA:** 2d6 + atributo, 10+ sucesso / 7–9 com custo / 6− movimento do Mestre. **Savage Worlds:** dado por perícia + dado selvagem, explosão, Bennies. **Shadowrun:** pool de d6, 5–6 conta.

## Lacunas do Nexus a considerar
1. **Graus de sucesso** (crítico ±10, 4 graus) como modo de dados.
2. **Estresse/consequências** (Fate) e **ferimento grave** (CoC) como alternativa de PV.
3. **Sorte/pontos de herói** como recurso global que reinicia rolagem.
4. **Nocautear** (corpo a corpo vira inconsciente) e **PV temporários**.
5. Ações por custo (PF2e) já cabem nas "Ações por turno".
