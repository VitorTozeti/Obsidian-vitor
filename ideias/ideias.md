# Ideias — caixa de entrada e como realizá-las

> **Regra:** ideia nova entra em [[ideias-inbox]] em 1 linha, na hora, sem julgar. Depois, se
> valer, ganha nota própria (modelo em [[ideia-template]]) e passa pelo [[ideias-como-realizar]].

## Como este hub funciona
1. **Captar** → [[ideias-inbox]] (uma linha: data + ideia + para quê).
2. **Avaliar** → nota atômica em `ideias/` com o [[ideia-template]] (problema, público, versão mínima).
3. **Realizar** → seguir o método de [[ideias-como-realizar]] (validar → MVP → decidir stack → virar projeto).
4. **Virou projeto** → criar `projetos/<slug>/` (hub + `<slug>-dados`, tag `proj/<slug>`, cor no graph — regras no `CLAUDE.md`) e trocar o status da ideia para `virou-projeto`, linkando o hub.
