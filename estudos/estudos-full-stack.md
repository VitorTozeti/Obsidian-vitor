# Estudos — Full-stack

Pré-requisito: o básico de [[estudos-front-end]] e [[estudos-back-end]].

## Trilha
- [ ] Contrato de API (OpenAPI), DTOs, validação nos dois lados
- [ ] Autenticação ponta a ponta: login, guardas de rota no front, RBAC no back, `returnUrl`
- [ ] Estado servidor × estado cliente, cache, paginação, tratamento de erro
- [ ] Banco: migrations, seed, backup; local-first × servidor
- [ ] Deploy: Docker Compose, Cloudflare/GitHub Pages, variáveis de ambiente
- [ ] CI (build+test no GitHub Actions), logs e monitoramento
- [ ] Projeto-âncora: um app CRUD completo com login, painel e relatório
