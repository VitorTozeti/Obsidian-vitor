# Estudos — Modelagem de Software

## Trilha
- [ ] Engenharia de requisitos: RF/RNF, regras de negócio, critérios de aceite, SRS
- [ ] Casos de uso e histórias de usuário
- [ ] UML: classes, sequência, atividades, estados, componentes
- [ ] Modelagem de dados: DER, normalização (1FN–3FN), chaves, índices
- [ ] Arquitetura: monólito modular, camadas, hexagonal, microsserviços (quando **não** usar)
- [ ] SOLID, padrões GoF (Factory, Strategy, Observer…), DDD básico (entidades, agregados, eventos)
- [ ] Documentar decisões (ADR) e manter diagramas no vault (Mermaid)
- [ ] Projeto-âncora: modelar do zero uma ideia da [[ideias-inbox]] antes de codar
